# 镜序重制：同步优先、场记为中心、剪辑时可随时检索

> 状态：产品与第一轮工程重制基线。基于 2026-11-17 用户实操访谈及 main `88e585e1`。
> 本文是改造约束，不代表本次提交已实现全部能力。

## 一句话定义

镜序是可跨项目复用的短剧多机位后期准备与检索工具：
**先把不可靠的音视频同步整理成可剪工程，立即交给剪辑师；后台再把实际拍摄内容关联到剧本、场记、演员与对白，让剪辑中的人随时找回素材。**

## 真实用户工作

- 每部新剧都应一键复用工作流，不再需要 Codex 逐项目搭建服务。
- 时间码会整体错位、局部错误、漂移或缺失；声音和其他证据用于补救，不得将相同对白跨 Take 误合。
- 同步优先。交付应提供完整多轨同步母版，以及尽可能保留原生多机位的目标 NLE 工程。
- 后续转写、镜头语义、场记、演员/角色与剧本关联可异步运行，不应阻塞首次同步工程交付。
- 场记是可交互的核心工作台：按真实拍摄顺序展示，自动生成候选，人工可以快捷添加无法识别的临时特写、OS 与补拍镜头。
- 剧本视图用于剪辑中找素材；演员临场发挥的实际对白必须可检索，不应仅依赖剧本原文。
- 多剪辑师通常分集工作，偶尔接力；各自复制原始素材到不同路径。共享媒体身份、关联关系与决定，不共享设备绝对路径。
- 剪辑师自行添加的音乐/音效归属剪辑工程资源，不应被当作摄影机原始机位。
- 目标 NLE 为 Resolve、Premiere、Final Cut Pro 与国内剪映专业版；均需真实 Windows/macOS/目标软件版本验收。剪映优先尝试现有工程导入路径，不以加密草稿写入为唯一出口。

## 用户必须看见的生产状态

新媒体目录项目的第一屏必须只有一个明确主任务：**同步并交付**。

第一屏应说明：
1. 已发现视频/音频数、机位识别情况、未确定项；
2. 当前运行阶段、最近一条进展、阶段检查点，以及最近一次状态更新；
3. 在有数据时展示可信进度；无可信分母时只显示活动，不伪造百分比或剩余时间；
4. 同步失败时显式展示原因及状态中心入口。重试不能复用已失效的旧结果；
5. 即使同步未完成，用户仍可进入素材库检查来源或恢复本机素材。尚无可靠 Take 的剧本与审阅可显示准备中，但不得伪造结果；
6. 同步完成后优先提示「核对同步」「导出同步母版」，而不是自动把用户扔进一整套剪辑器。

## 两条时间线，两个责任

**同步母版**：保留原始视频轨、独立录音、相对偏移、时间基、同步置信度与人工纠正。可预览/播放/检查，作为导出依据，不做创意剪辑。

**组接/交付**：使用人工确认的选片和剧本顺序形成起点，不替代 DaVinci、Premiere、FCP 或剪映的帧级精剪。

两者必须视觉分离，不能在同一屏同时展开多个争夺注意力的时间轴。同步母版一旦交付，后台 AI 只能提出修正，不得静默改写已分发版本。

## UI 信息架构（目标，分阶段落实）

- 新项目：**同步与交付**为第一动作，只有必要的输入检查、进度、异常与导出。
- 完成首次交付后：**场记**作为日常默认工作台，按实际拍摄顺序；从场记可进入剧本位置、素材、演员和实际对白。
- 剪辑过程中：**剧本检索/语义检索**为常驻辅助入口，找到片段后提供本机定位与目标 NLE 交接。
- 复杂模型、运行时、状态修复置于进阶页，不阻塞基本剪辑准备。
- 可保留已有四域内部 API 与 authority，但不以四域导航代替首次任务引导。

## 复用与不重造

- 继续使用已有第一方同步引擎、媒体身份与 relink、Timeline Core、NLE 导出器；从可验证的薄切片修复，而非推倒可用的数据层。
- FFmpeg/ffprobe、OpenTimelineIO、PySceneDetect、ASR/视觉 Provider 继续按成熟组件复用。
- 无需先建设 NLE、通用 MAM、完整场记替代品、团队实时编辑服务器或加密草稿逆向框架。

## 发布/验收红线

### 近期 P0
- sync worker 的真实阶段进度贯穿 Task Store → Host → Desktop；不能只在引擎回调而没有持久化。
- 运行/失败/中断/完成/无法读取状态在第一屏区分，并明确操作方向。
- 用真实素材完成同步、听看核对、导出，实际在至少一款目标 NLE 导入。
- 多轨同步母版和原生多机位素材分别验证，不因 XML 可导入就宣称原生多机位交付完成。
- 当前 HEAD 的 CI 失败先修清，不以旧 commit 的绿灯替代。

### 随后 P1
- 同步页可选中具体片段并预览对齐，支持检查漂移和未确认项。
- 场记按拍摄顺序、可交互补录并附实际视频证据。
- 剧本映射与实际台词检索可在剪辑过程中持续使用。
- 团队共享的是内容身份和项目关系；剪辑师本地媒体 binding 独立。
- 独立录音与音乐/音效采用不同生命周期，前者进同步源，后者归剪辑项目资产。

**判断是否成功的标准不是页面数或测试数，而是：新项目不依赖 Codex 人工编排就能在可理解的状态下完成同步、核对、导出，剪辑师能开始剪；后台分析完成后，还能明显缩短找素材的时间。**
