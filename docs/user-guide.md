# 镜序当前测试版使用提示

> 2026-11-17。**这里区分目标与现有功能，不作生产可用承诺。** 产品定义 [`product/REBUILD_2026-11-17.md`](./product/REBUILD_2026-11-17.md)，实际状态 [`engineering/STATUS.md`](./engineering/STATUS.md)。

## 首次新建媒体目录项目

优先打开「同步与交付」，检查媒体目录和识别机位，再开始同步。任务运行时查看当前阶段、最近活动和错误；同步算法检查点不等于全项目百分比。同步期间也可以进入「检查素材」或「状态中心」，不应被锁在无法诊断的页面里。

当前同步时间轴**仍是只读概览**，无法代替真实多轨音画播放和手动对轨。导出的 FCPXML / Premiere XML 需要实际在目标剪辑软件打开验收。能够导入多轨不证明已经得到原生可切机位素材，国内剪映 Windows/macOS 也需要按版本单独测试。

## 同步完成后

「场记」用于按**实际拍摄顺序**查看 Take、机位和拍摄备注；「剧本」用于按故事顺序查找素材；「审阅」记录人工看片结论。演员实际对白、镜头语义、临时特写与 OS 的自动归集是重制目标，不能假设目前已稳定完成。

四个内部工作区不是用户必须先做完的四道门槛。AI 只提供证据或候选，人工确认和已分发的同步母版不能被自动改写。

不同剪辑师的文件绝对路径可能不相同。跨机交接依赖稳定 `media_id` 和本机 media binding，不应把路径写死在共享项目文件。独立 WAV 录音与后期添加的音乐/音效是不同资产。

问题未解决前先查看最近任务记录与失败原因，勿把“界面停止变化”直接当作已完成或彻底卡死。更完整的未完成项目见 [`engineering/BACKLOG.md`](./engineering/BACKLOG.md)。
