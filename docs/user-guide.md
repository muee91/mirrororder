# 镜序当前测试版使用提示

> 2026-11-17。开发中的模块分离不等于已经通过生产验收。唯一产品目标见 [`product/REBUILD_2026-11-17.md`](./product/REBUILD_2026-11-17.md)，已证实的状态见 [`engineering/STATUS.md`](./engineering/STATUS.md)。

## 新剧第一次使用

1. 在项目管理中选择「新建项目」。**目前创建表单仍要求选择剧本文件**，无剧本先同步是后续需要实现的产品目标，不能把视觉稿当作已完成的功能。
2. 原始素材项目打开「同步任务」，查看媒体、机位和音频同步引擎的真实阶段、最近进展与错误。任务尚未完成时可进入「素材库」或「本机素材」检查硬盘。
3. 同步完成后，从「同步核对」选中机位、时间轴片段并预览原始视频，再去独立的「工程交付」查看实际生成的 XML / FCPXML。
4. 工程交付不要求完成场记和 AI 分析；但目前仍缺独立 WAV 对轨、帧级偏移修正和四款剪辑软件的完整原生多机位实机验收，不能拿它直接宣称全部同步准确。
5. 完成同步工程交付后，继续使用「交互场记」「剧本关联」「演员与角色」「素材库」「看片审阅」「选片组接」等独立模块。

## 安全与常见问题

- 旧项目在本机保存的页面历史会被兼容读取；同步任务、同步核对和工程交付是不同页面，不再是时间线里的多块平级面板。
- 重新同步将更新本机同步结果。已分发剪辑师的工程要单独保存并记录版本，不得无提示地当作自动更新。
- 已生成文件可以在本机文件管理器中显示，不代表 Resolve、Premiere、Final Cut Pro、国内剪映 Windows/macOS 都已完成导入验收。同步多轨与可切换机位分开检查。
- 不同剪辑师的硬盘绝对路径不同；共享项目请只使用稳定媒体身份和 device-local binding。
- 模型是后台补充证据的计算资源；它的结果不得静默覆盖人工确认的场记、剧本 placement 或同步母版。
