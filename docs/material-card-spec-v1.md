# 镜序素材卡片规范 v1

素材卡片服务后期剪辑，不是算法仪表盘。它的第一任务是让剪辑师在高密度素材浏览中快速回答：**这是什么素材、哪个机位、什么景别、能不能播、当前是否选中。**

## 1. 数据粒度

景别属于 **angle / clip（机位素材）级事实**，不得提升为 Take 级事实。一个多机位 Take 可以同时存在 A 机近景、B 机中景、C 机全景。

标准景别值：

- `unknown` — 未标
- `wide` — 全景
- `full` — 全身
- `medium` — 中景
- `medium_closeup` — 中近景
- `closeup` — 近景
- `extreme_closeup` — 特写
- `insert` — 细节

人工场记景别优先于 AI 推断；AI 可以给候选，但不能静默覆盖人工值。

## 2. 卡片固定信息层级

素材卡片从高到低只显示这些信息：

1. **画面/素材身份**：缩略图（本机可用时）或稳定占位；
2. **机位**：A / B / C / 航 / 空 / G / 辅；
3. **文件名**：单行截断，完整路径只放 tooltip / inspector；
4. **景别**：全景 / 中景 / 近景 / 特写等；未标时显示弱化的“景别—”；
5. **时长或片内范围**；
6. **素材角色**：同步机位、航拍、B-roll、GoPro、细节、自定义；
7. **状态装饰**：选中、设备缺失、重复机位、场记首选。

素材卡片**不得**显示或强调：

- Take↔剧本匹配的高/中/低置信；
- 匹配评分百分比；
- Editorial Best / Reject 作为素材固有属性；
- 大段算法解释。

这些属于关系层或决定层，应放在 Take 行、剧本关系区或检查器中。

## 3. 交互

### macOS Production

- 单击素材卡：选中并监看；
- 景别必须能从选中素材卡附近直接修改，不能要求进入备注；
- 同一 Take 的每个机位分别保存景别；
- 右键素材卡也应提供景别快速菜单；
- 修改先进入场记 draft，随场记 revision 一起保存；
- “场记首选”只表示场记推荐机位，不等价于 Editorial Best。

### Team Web

Team Web 是后期审阅投影。素材卡展示场记已经确认的景别，但不在 Web 中改写场记事实。景别来自 `script-supervisor.v2` 的 attachment 投影。

## 4. 视觉尺寸

- 紧凑卡：约 160–180 px 宽，64–76 px 高；
- 检查器卡：约 280 px 宽，允许缩略图更大；
- 同一列表中的卡片保持定宽定高，不根据文件名或算法状态跳动；
- 机位使用稳定的小色块；景别使用独立、低饱和标签；
- 选中态用描边 + check，不用大面积高饱和底色；
- 设备缺失必须显式可见，但不改变卡片尺寸。

## 5. 后期优先级

剪辑师浏览素材时的优先信息顺序：

**画面 → 机位 → 景别 → 时长 → 可用范围 → 人工备注 → 剧本关系 → AI 解释。**

因此 AI 置信、评分、审计信息不得抢占素材卡主体。镜序所有新素材卡界面应遵循这一顺序。
