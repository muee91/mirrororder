# App Information Architecture

镜序 App 是 Production 工作台。它应该把复杂能力组织成剪辑人员理解的制作对象与工作阶段，而不是把内部模块平铺成一级导航。

## 全局壳层

项目是长期上下文，常驻左栏。

```text
镜序

项目
  项目 A
  项目 B
  项目 C

状态中心
设置
```

选择项目后，中央区域直接进入该项目工作区，不再经过“中央项目列表 + 右侧 Inspector”的中转页面。

### 启动与恢复

正常启动路径以“继续制作”为目标，而不是让用户先理解 Host、端口或 WorkspaceRegistry。

- 成功打开过的本机 workspace 可以作为设备本地恢复上下文；仅选择但未成功打开的路径不能写入恢复状态。
- App 再次启动时，优先自动打开上次成功 workspace，并恢复上次项目。
- 已有项目恢复到该项目上次离开的 Production 二级页面；没有页面历史的项目第一次进入默认落到“素材 → 素材库”。
- workspace 已打开但没有可恢复项目时，不依赖服务端项目数组顺序自动选择；停在项目选择态。
- 上次 workspace 丢失或无法打开时进入明确的重新定位/恢复状态，不删除或改写项目数据。
- Host 地址、连接已运行服务、workspace 路径编辑和运行诊断属于低频“工作区与连接 / 高级连接”，不得重新成为默认首页的主要视觉对象。
- 用户可以关闭下次自动恢复；这只清除设备本地启动偏好，不删除项目级页面历史或生产数据。

启动路径的产品语义是：

```text
打开镜序
  ↓
恢复上次成功 workspace
  ↓
恢复上次 project
  ↓
恢复该 project 上次 Production page
```

首次使用或没有有效恢复上下文时：

```text
打开镜序
  ↓
打开工作区
  ↓
选择 / 创建项目
  ↓
素材 → 素材库
```

### 项目左栏

项目行只展示：

- 项目名称
- 当前后台阶段或 Take 数
- 明确待处理数量

低频操作进入项目行上下文菜单：团队审阅、Finder、重新整理、素材目录、删除。

### 状态中心

同步、转写、剧本匹配、内容识别、人物、声纹、Audit 等后台工作统一进入状态中心。

项目工作区只保留轻量活动条，不重复展示完整日志和任务控制。

状态中心的目标是回答：

- 哪个项目正在处理？
- 处理到什么阶段？
- 是否失败？
- 是否需要人工处理？

它不展示模型实现细节作为普通用户主信息。

## 项目 Production 分区

项目顶部只保留四个一级制作区：

### 素材

- 素材库
- Take
- 人物
- 场记

### 剧本

- 剧本
- 覆盖

### 剪辑

- 粗剪
- 组接

### 审阅

- 看片
- 待处理
- 概览

`Audit`、`Agent`、`IdentityIndexer`、`Coverage Graph`、`Delivery Resolver` 等工程名不能继续膨胀成一级导航。

## 场记是独立大工作区

场记不是 Take 详情表单。进入“素材 → 场记”后，场记工作区占据中央 Production 画布，普通剧本/Take/Viewer 工作台暂时隐藏。

场记布局：

```text
待录入素材 |              电子场记表
            |
Take        | 素材 | 集 | 场 | 镜 | 次 | 状态 | 可用范围 | 备注
文件搜索    |
Finder拖入  |
```

视频预览属于场记的临时工具，而不是永久占据一整列。需要看片时浮出或展开。

## App / Web 边界

App 承担：

- 项目与本机素材
- 自动生产任务
- 素材角色、机位和场记
- Coverage / Rough Cut / Assembly 生产准备
- 模型与本地运行时
- 最终 Editorial Decision
- NLE 生产输出

Team Web 承担：

- 播放
- 剧本 / Take 审阅
- Individual Opinion
- 人工归集
- 团队协作
- 安全的人物、场记、分析上下文

Web 不出现场记编辑、素材目录、同步策略、模型连接、运行时或生产任务控制。

## 信息架构原则

1. 项目是一级对象，Workspace 是底层隔离概念。
2. 素材和制作阶段是用户语言，内部算法模块不是导航语言。
3. 后台分析统一进入状态中心。
4. 一个能力只有一个明确的“家”；其它位置只能提供快捷入口。
5. 高频生产工作允许占满中央画布，例如电子场记表。
6. 普通看片工作区保持剧本 / Take / Viewer 的成熟结构。
7. 新能力优先加入现有分区的二级入口，除非它形成新的稳定用户对象。
8. 默认启动路径必须恢复用户工作现场；Host、端口和 workspace 路径只在恢复失败或高级连接时成为显式对象。
